## 👨‍💻 About Me

I am a **Data Engineer** focused on building reliable, scalable, and maintainable data platforms. My work spans cloud data engineering, ELT/ETL development, analytics engineering, orchestration, and business-focused data products.

I enjoy turning raw data into trusted, documented, and useful datasets through:

- 🏗️ **Data pipelines and orchestration** with Dagster, Azure Data Factory, and Spark
- ☁️ **Cloud data platforms** across Azure and AWS, with experience exploring Snowflake
- 🔄 **Analytics engineering** using dbt, reusable macros, testing, documentation, and snapshots
- 📊 **Data modeling** for marketing, commerce, CRM, and operational analytics
- 🤖 **Intelligent analytics** through semantic layers and agentic data applications

> I build data systems that are not only functional, but also observable, testable, and easy for teams to use.
